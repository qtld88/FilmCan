## Suggested merge order

1. **#2** first-launch defaults. #7 is stacked on it.
2. **#3** phone QR, **#4** more cameras, **#5** reports on the Mac. These three are independent of each other.
3. **#6** calm main screen.
4. **#7**, then **#8**, then **#9**, which form a stack. Merge each one before the next.
5. **#10** recognition page, after #8 and #4.
6. **#11** re-create report, after #5.
7. **#12** demo, then **#13** speed advice.

These PRs are likely to conflict, and need to be resolved by hand when merging:
- **#6, #8, #9 and #13** all touch `BackupEditorView+Overview.swift`. #13 only adds one view at the end of `overviewSection`.
- **#6, #8 and #12** all touch `MainView.swift`.
- **#10 and #12** both touch `RollNumberer.swift` (`RollNumberingStore`). #10 adds forget helpers; #12 adds `remove(configId:)`.
- **Almost every PR** appends a section to `docs/smoke-qa-checklist.md`. Keep every section.

After merging, run `xcodegen generate`, because several lots add new files. Then run the full smoke pass on the real app.
